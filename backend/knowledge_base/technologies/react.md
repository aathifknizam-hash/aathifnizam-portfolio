# React

## What it is

React is a JavaScript frontend library for building interactive user interfaces using reusable components.

## Why Aathif used it

Aathif used React in the Smart Service Desk project and the Healthcare Management System project described in the resume. The frontend needed to support dashboards, role-based access, and interactive workflows for support and healthcare operations.

## Where it was used

- Smart Service Desk frontend
- Healthcare Management System frontend
- Portfolio UI

## How it was implemented

The Smart Service Desk repository uses a Vite-based React frontend with role-based dashboards and service integrations. The healthcare project also includes React interfaces for admin, receptionist, doctor, lab technician, and pharmacist workflows.

## Components

- Component-based UI
- Route-based screens
- Dashboard views
- API integration with the backend

## Interview Explanation

"React was useful in my projects because it let me build role-based dashboards and dynamic workflows quickly. I used it to create interfaces that communicate cleanly with the backend and keep the user experience focused on the actual business process."
